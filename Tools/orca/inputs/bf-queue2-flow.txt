# The whole casual queue2 flow in one run (ORCA.md "The queue's character select"),
# Brawl: boot -> the main menu -> PLAY ONLINE > With Anyone > Casual -> the player's own
# character select (the solo header): port 1 takes Mario and presses Start (ready) -> from
# ORCA_TEST_QUEUE_PICK's frame port 2 plugs in with its pick (Link), the header becomes the room's
# (queue2) and the pick is steered in -> both press Start (ready) -> Orca presses Start -> the
# casual stage pick (port 1 names Battlefield, port 2 Yoshi's Island; the coin takes one) -> port 2
# walks off three times -> results -> game 2's character select, both ready again.
# Run with ORCA_TEST_QUEUE=casual:solo ORCA_UX_TEST_NAMES=ada,bo
# ORCA_TEST_QUEUE_PICK=<the solo character select's frame + 300>:3:2:-7.5:14.23, e.g. the sync test
# from the main menu on (YG_SYNCTEST=7 YG_SYNCTEST_FROM=1440).
@scStrap mash 30 99999 1 40 A
@scBoot mash 30 99999 1 40 A
@scTitle mash 30 99999 1 40 A
# PLAY ONLINE, With Anyone, Casual.
@muMenuMain:1 120 123 1 DOWN
@muMenuMain:1 170 173 1 A
@muMenuMain:1 220 223 1 RIGHT
@muMenuMain:1 270 273 1 A
@muMenuMain:1 320 323 1 A
# The player's own character select: up into the grid, A on Mario, Start (ready: the page would
# search now). Port 2 isn't plugged in yet.
@scSelctCharacter:1 113 153 1 SY=255
@scSelctCharacter:1 173 176 1 A

# The room's character select (port 2 from the pick's frame, about 300 frames in): both ready.
@scSelctCharacter:1 mash 600 99999 1 30 START
@scSelctCharacter:1 mash 620 99999 2 30 START

# masked on port 1's turn). Then port 2 goes down onto Yoshi's Island and names it.
@scSelStage:1 40 59 1 SY=255
@scSelStage:1 40 59 2 SY=255
@scSelStage:1 62 64 1 SX=1
@scSelStage:1 62 64 2 SX=1

@scSelStage:1 160 162 2 A
# Port 2 walks off the left edge, three stocks.
@scMelee 250 99999 2 SX=1
@scVsResult mash 240 99999 1 40 A
@scVsResult mash 260 99999 2 40 A
@scVsResult mash 600 99999 1 40 START
@scVsResult mash 620 99999 2 40 START
# Game 2: back on the room's character select, characters free: both ready again.
@scSelctCharacter:2 mash 120 99999 1 30 START
@scSelctCharacter:2 mash 140 99999 2 30 START
